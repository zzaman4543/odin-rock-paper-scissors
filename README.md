# Rock Paper Scissors Project

[Rock Paper Scissors](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors) is the third project in the [The Odin Project](https://www.theodinproject.com)'s [Foundations](https://www.theodinproject.com/paths/foundations/courses/foundations) path.

## Skills Gained

Completing this project taught me the fundamentals of programming, which I applied though JavaScript. For example, I've learnt about variables, operators, data types, conditionals, and functions.
